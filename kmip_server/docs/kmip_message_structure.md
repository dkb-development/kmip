# KMIP Message Structure

## TTLV Encoding

KMIP uses a Tag, Type, Length, Value (TTLV) encoding for all messages. Each TTLV item consists of:

- **Tag** (4 bytes): Identifies the field
- **Type** (1 byte): Indicates the data type
- **Length** (4 bytes): Specifies the length of the value in bytes
- **Value** (variable): The actual data
- **Padding** (0-7 bytes): Padding to ensure 8-byte alignment

```
┌───────────┬──────┬────────┬───────────────────┬─────────┐
│    Tag    │ Type │ Length │       Value       │ Padding │
│  (4 bytes)│(1 B) │(4 bytes)│  (Length bytes)   │(0-7 B)  │
└───────────┴──────┴────────┴───────────────────┴─────────┘
```

## TTLV Encoding Example

Here's an example of how a TTLV-encoded field might look in hexadecimal:

```
42 00 57 05 00 00 00 04 00 00 00 02 00 00 00 00
```

Breaking this down:
- `42 00 57`: Tag (0x420057) - Object Type
- `05`: Type (0x05) - Enumeration
- `00 00 00 04`: Length (4 bytes)
- `00 00 00 02`: Value (2) - Symmetric Key
- `00 00 00 00`: Padding (4 bytes)
